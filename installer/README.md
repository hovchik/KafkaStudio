# KafkaStudio installer

Builds a Windows installer (`KafkaStudioSetup-<version>.exe`) for KafkaStudio using
[Inno Setup 6](https://jrsoftware.org/isdl.php).

## One-time setup

Install Inno Setup 6 (free): https://jrsoftware.org/isdl.php

## Build

From the repo root:

```powershell
pwsh tools/Publish.ps1 -Version 1.0.0
```

This will:
1. Run `dotnet publish` for `KafkaStudio.App` (self-contained `win-x64`, so end users don't need
   the .NET runtime installed) into `publish/win-x64`.
2. Compile `installer/KafkaStudio.iss` with Inno Setup's `ISCC.exe`, producing
   `installer/output/KafkaStudioSetup-1.0.0.exe`.

Pass `-SkipInstaller` to only publish (e.g. if Inno Setup isn't installed yet):

```powershell
pwsh tools/Publish.ps1 -Version 1.0.0 -SkipInstaller
```

## What the installer does

- Installs to `Program Files\KafkaStudio` (per-machine, 64-bit).
- Adds Start Menu shortcuts (and an optional desktop shortcut).
- Uses the app icon (`src/KafkaStudio.App/Assets/app.ico`) for the installer, shortcuts, and
  Add/Remove Programs entry.
- Offers to launch KafkaStudio after install.
- Registers a standard uninstaller.

## Icon

The app icon is generated by `tools/GenIcon.ps1` (System.Drawing, Windows-only) into
`src/KafkaStudio.App/Assets/app.ico`, and wired up via `KafkaStudio.App.csproj`'s
`<ApplicationIcon>` (exe icon) and `MainWindow.axaml`'s `Icon="/Assets/app.ico"` (window/taskbar
icon). Re-run `tools/GenIcon.ps1` if you want to regenerate/tweak it.
